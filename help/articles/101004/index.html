Creating Posts

Creating your first posts on Hydraulisc

Important!

NOTICE: As per the Guidelines, you should only post content that you have the right to share!


Posts Creator

Firstly, make sure you are on an official Hydraulisc App/Site, and logged in.

It is recommended to have JavaScript enabled for the best posting experience!

  1. Navigate to the post creator. If you get redirected to the login page, login and try again.
  2. OPTIONAL - Add a post title/header or short description. We give you up to two thousand two hundred (2200) characters to caption your post.
  3. Select a nice image to post. You can't post nothing.
    • PNG, JPEG, GIF & WebP formats are supported.
    • 25Mb file size hard limit.
    • Basic HTML styling is allowed:
      • <b>bold</b>
      • <i>italic</i>
      • New lines
        are automatically formatted
      • https://example.com automatically becomes a link! (https://example.com)
  4. You should get a preview of the image you selected.
  5. Happy with the result?
    Upload!

If you have issues with any of the steps mentioned above, feel free to request additional support in our Discord.
